# Рулетка Жизни — Phase 1.5a: Классы персонажей

- **Дата:** 2026-05-04
- **Версия:** spec v3 (расширение Phase 1, отдельная подфаза 1.5a)
- **Статус:** Draft, ожидает ревью
- **Базовый spec:** [2026-04-30-life-roulette-design-v2.md](2026-04-30-life-roulette-design-v2.md)
- **Авторы дизайна:** юный разработчик (9-10 лет) + папа

## Журнал изменений

Этот документ — **расширение** базового spec v2. Никакие правила базы не отменяются. Добавляется новая система: классы персонажей, покупаемые в магазине.

Изменения базовой механики:
- Жизни игрока больше не строго целые. Могут быть **дробные с шагом 0.5** (например, 3.5 жизни) — это нужно для брони Спецназа.
- В магазин добавлены 5 новых товаров — наборы классов.
- Перед началом игры каждый игрок выбирает класс из числа купленных (или играет без класса).

## 1. Обзор

Phase 1.5a добавляет систему классов: 5 покупаемых наборов из магазина, каждый меняет начальные условия и/или правила для конкретного игрока. Классы — это **разовая покупка**, после неё класс доступен для использования в любых играх. За одну игру игрок может выбрать только **один класс** или играть без класса.

Игра без класса работает по правилам Phase 1.

## 2. Цели Phase 1.5a

- Дать стратегическую глубину игре через выбор класса
- Сохранить балансовый принцип "цена ↔ сила": дешёвые классы → небольшое преимущество, дорогие → серьёзное
- Не сломать базовую механику: игроки без классов должны нормально соревноваться с классами на старте

## 3. Не-цели

- ❌ Несколько классов на одного игрока в одной игре
- ❌ Уровни прокачки внутри класса
- ❌ Совместимость с онлайн-мультиплеером (Phase 3 — отдельный спек)
- ❌ Сюжет / фоновые истории классов
- ❌ DuelScene (Phase 1.5c)
- ❌ Спецпатроны (Phase 1.5b)

## 4. Глоссарий

| Термин | Что это |
|--------|---------|
| **Класс** | Готовый набор способностей для игрока (медик, танк, спецназ, двойник, бог) |
| **Класс куплен** | Запись в профиле игрока: ID класса доступен для выбора перед игрой |
| **Класс активен** | В текущей игре выбран этот класс — все его способности применяются к игроку |
| **Способность** | Эффект класса (увеличенная аптечка, броня, нож, молния, и т.д.) |
| **Дробная жизнь** | Жизнь с шагом 0.5: значения вида 3.5, 2.5, 0.5 |

## 5. Список классов

### 5.1. Медик — 200 валют

| Параметр | Значение |
|----------|----------|
| Цена покупки | 200 |
| Стартовые жизни | 4 |
| Эффект | Шоколадка восстанавливает **+3 жизни** (вместо +1) |

**Реализация:**
- При классе `medic` обработка `use-item` для `chocolate` использует delta = +3 (не +1)
- Лимит "макс 4 жизни" сохраняется (clamping)
- Стандартное правило "шоколадка ≤1 раз за ход" сохраняется

### 5.2. Танк — 300 валют

| Параметр | Значение |
|----------|----------|
| Цена покупки | 300 |
| Стартовые жизни | 4 |
| Эффект | **Один раз за всю игру** автоматически блокирует входящий боевой выстрел |

**Реализация:**
- Состояние класса: `tankBlockUsed: boolean` (default `false`)
- При обработке выстрела: если цель — Танк, патрон `live`, `tankBlockUsed === false` → блок срабатывает: `tankBlockUsed = true`, урон 0
- Эмитится событие `tank-block-triggered`
- Срабатывает только на **боевые выстрелы**. Молния Бога проходит мимо (Танк не блокирует молнию)
- Срабатывает на любой live: и в Танка, и self-shot Танком в себя

### 5.3. Спецназ — 400 валют

| Параметр | Значение |
|----------|----------|
| Цена покупки | 400 |
| Стартовые жизни | 4 |
| Эффект | Стартует в броне |

**Броня:**
- Действует на **3 раунда** (3 обоймы) ИЛИ до получения **3 попаданий**, что раньше
- Каждое попадание (любым "негативным уроном" — боевой патрон, молния Бога) — урон **уменьшается вдвое**: `damage / 2`
- Урон может быть дробным (0.5, 1, 2)
- При нанесении урона расходуется заряд брони
- При истечении 3 раундов или 3 зарядов — броня ломается, дальнейшие попадания идут с полным уроном

**Реализация:**
- Состояние класса: `armorChargesLeft: number` (default 3), `armorRoundsLeft: number` (default 3)
- На событии `chamber-loaded` (новая обойма): если есть броня, `armorRoundsLeft -= 1`. Если стало 0 → броня ломается, эмитится `armor-broke`
- При входящем damage в Спецназа в броне: `effectiveDamage = damage / 2`, `armorChargesLeft -= 1`. Если `armorChargesLeft === 0` после этого → броня ломается, эмитится `armor-broke`

### 5.4. Двойник — 5000 валют

| Параметр | Значение |
|----------|----------|
| Цена покупки | 5000 |
| Стартовые жизни | **5** (вместо 4) |
| Эффект 1 | Доп. жизнь на старте |
| Эффект 2 | Активный предмет "Нож" — 1 раз за игру |

**Нож:**
- Используется как item на ходу (фаза `turn-item`) — действие `use-item: knife`
- После активации: следующий **боевой** выстрел Двойника наносит **2× урон** (т.е. -2 жизни вместо -1)
- **Холостые выстрелы не тратят нож** — нож остаётся "взведённым" до первого боевого
- После одного срабатывания эффект исчерпан

**Реализация:**
- Новый ItemId `knife`, добавлен только Двойнику (1 шт. в стартовом инвентаре, не покупается отдельно)
- Состояние класса: `knifeArmed: boolean` (default `false`), `knifeUsed: boolean` (default `false`, после срабатывания)
- `use-item: knife` → требует `knifeUsed === false` и `knifeArmed === false` (одноразовая активация). Устанавливает `knifeArmed = true`. Расходует нож из инвентаря (`inventory.knife = 0`)
- При обработке выстрела Двойника: если `knifeArmed && bullet === 'live'` → `effectiveDamage = damage * 2`, `knifeArmed = false`, `knifeUsed = true`. Эмитится `knife-doubled-damage`
- Если выстрел холостой при `knifeArmed`: нож остаётся, ничего не меняется
- Стандартный лимит "1 предмет того же типа за ход" применяется к ножу — но т.к. лимит 1 за всю игру, это автоматически выполняется

**Лимит инвентаря:** 5 ножей в инвентаре профиля **не имеет смысла** — нож выдаётся автоматически при выборе класса. Профиль не накапливает ножи между играми (нож обнуляется на конец игры).

### 5.5. Бог — 10000 валют

| Параметр | Значение |
|----------|----------|
| Цена покупки | 10000 |
| Стартовые жизни | 4 |
| Эффект | Способность "Молния" |

**Молния:**
- Действие `use-ability: lightning` — **дополнительное к обычному ходу**
- Может быть использовано на своём ходу (фаза `turn-item`) — независимо от выстрела
- Цель: любой **живой противник** (нельзя в себя)
- Эффект: цель получает **1 урон** (если в броне Спецназа — 0.5)
- Танк **не блокирует** молнию (только боевые патроны)
- **Лимит за раунд:** 1 молния (сбрасывается на новой обойме)
- **Лимит за игру:** 4 молнии всего

**Реализация:**
- Состояние класса: `lightningUsedThisChamber: boolean` (default `false`), `lightningTotalUsed: number` (default 0)
- Action: `{ type: 'use-ability'; ability: 'lightning'; targetId: string }`
- Валидация:
  - класс должен быть `god`
  - `!state.lightningUsedThisChamber`
  - `state.lightningTotalUsed < 4`
  - target существует, жив, не сам Бог
- На применение: target теряет жизни (с учётом брони цели), `lightningUsedThisChamber = true`, `lightningTotalUsed += 1`
- При `chamber-loaded`: сбрасываем `lightningUsedThisChamber = false`
- Эмитится событие `lightning-cast`
- Не считается выстрелом — обычный выстрел всё ещё обязателен на этом ходу

## 10. Игрок — изменения

```typescript
interface Player {
  id: string;
  name: string;
  profileId: string | null;
  lives: number;             // ИЗМЕНЕНО: теперь может быть дробным с шагом 0.5
  inventory: Record<ItemId, number>;
  isBot: boolean;
  eliminated: boolean;
  classId: ClassId | null;   // НОВОЕ: выбранный класс или null (без класса)
  classState: ClassState;    // НОВОЕ: per-class state machine (см. ниже)
}

interface ClassState {
  // Tank
  tankBlockUsed: boolean;
  // Specops
  armorChargesLeft: number;
  armorRoundsLeft: number;
  armorActive: boolean;       // вычислимое поле, но кешируется для удобства
  // Double
  knifeArmed: boolean;
  knifeUsed: boolean;
  // God
  lightningUsedThisChamber: boolean;
  lightningTotalUsed: number;
}
```

При `initGame`: в зависимости от `classId` инициализируется `classState` соответствующими дефолтами:

| Класс | Стартовые жизни | classState |
|-------|------------------|------------|
| medic | 4 | все false / 0 |
| tank | 4 | tankBlockUsed=false |
| specops | 4 | armorActive=true, armorChargesLeft=3, armorRoundsLeft=3 |
| double | **5** | knifeArmed=false, knifeUsed=false, knife в инвентаре |
| god | 4 | lightningUsedThisChamber=false, lightningTotalUsed=0 |
| null | 4 | все false / 0 |

## 11. Engine — изменения

### 11.1. Damage pipeline

Текущий код:
```
damage = bullet === 'live' ? 1 : 0;
target.lives -= damage;
```

Новый pipeline (псевдокод):

```typescript
function resolveDamage(target: Player, baseDamage: number, source: 'bullet' | 'lightning'): { finalDamage: number; events: GameEvent[] } {
  let damage = baseDamage;
  const events: GameEvent[] = [];

  // Tank: блокирует только bullet (не lightning)
  if (target.classId === 'tank' && source === 'bullet' && !target.classState.tankBlockUsed && damage > 0) {
    target.classState.tankBlockUsed = true;
    events.push({ type: 'tank-block-triggered', playerId: target.id });
    return { finalDamage: 0, events };
  }

  // Specops armor: половинит любой damage > 0
  if (target.classId === 'specops' && target.classState.armorActive && damage > 0) {
    damage = damage / 2;
    target.classState.armorChargesLeft -= 1;
    if (target.classState.armorChargesLeft <= 0) {
      target.classState.armorActive = false;
      events.push({ type: 'armor-broke', playerId: target.id });
    }
  }

  return { finalDamage: damage, events };
}
```

### 11.3. Медик аптечка + общий кап жизней

В обработке `use-item: chocolate`:

```typescript

const maxLives = player.classId === 'double' ? 5 : 4;

```

**Логика кап:**

- Все остальные (включая Медика): max 4
- Двойник + Медик невозможен (один класс на игру)

### 11.4. Бог молния — новый action

```typescript
case 'use-ability': {
  if (action.ability !== 'lightning') {
    throw new Error(`Unknown ability: ${action.ability}`);
  }

  const caster = state.players[state.currentPlayerIndex]!;
  if (caster.classId !== 'god') throw new Error('Only god can cast lightning');
  if (caster.classState.lightningUsedThisChamber) throw new Error('Lightning already used this chamber');
  if (caster.classState.lightningTotalUsed >= 4) throw new Error('Lightning total limit reached');

  const targetIdx = state.players.findIndex(p => p.id === action.targetId);
  if (targetIdx < 0) throw new Error(`Target ${action.targetId} not found`);
  const target = state.players[targetIdx]!;
  if (target.eliminated) throw new Error('Target eliminated');
  if (target.id === caster.id) throw new Error('Cannot cast lightning on self');

  // Apply damage with armor reduction (Tank does NOT block lightning per spec 5.2)
  const { finalDamage, events: damageEvents } = resolveDamage(target, 1, 'lightning');

  // Mutate target lives
  const newLives = target.lives - finalDamage;
  const eliminated = newLives <= 0;
  const newPlayers = [...state.players];
  newPlayers[targetIdx] = { ...target, lives: newLives, eliminated };

  // Update caster counters
  const newCaster = {
    ...caster,
    classState: {
      ...caster.classState,
      lightningUsedThisChamber: true,
      lightningTotalUsed: caster.classState.lightningTotalUsed + 1,
    },
  };
  newPlayers[state.currentPlayerIndex] = newCaster;

  events.push(...damageEvents);
  events.push({ type: 'lightning-cast', casterId: caster.id, targetId: target.id, damage: finalDamage });
  if (finalDamage > 0) {
    events.push({ type: 'lives-changed', playerId: target.id, newLives });
  }
  if (eliminated) {
    events.push({ type: 'player-eliminated', playerId: target.id });
  }

  // Note: молния не заканчивает ход. Игрок всё ещё ОБЯЗАН выстрелить.
  // Phase остаётся 'turn-item' до выстрела.

  return {
    state: {
      ...state,
      players: newPlayers,
      actionLog: [...state.actionLog, action],
    },
    events,
  };
}
```

## 12. PlayerView — изменения

`PlayerView.otherPlayers` дополняется полем `classId` (публичная инфа — все знают чей класс).

`selfPlayer` имеет полный `Player`, включая `classState`.

**`otherPlayers[].classState` НЕ включается в view** — другие игроки не видят счётчики чужой брони/ножа/молний (приватные флаги — за исключением видимых эффектов вроде "у Спецназа всё ещё броня"). Для UI достаточно знать `classId` оппонента.

Спорная деталь — "осталось ли броня": игроки могут видеть уведомления о "armor-broke", т.е. знать когда броня ломается. Но точное число зарядов — приватно.

## 13. Бот — изменения

Бот в режиме vs AI выбирает случайный класс. Алгоритм декларации:

```typescript
function botDecide(view, rng, ctx): Action {
  // ... существующая логика ...

  // Новые ветки:
  // 1. Если бот — Бог и есть молнии: использует молнию ПЕРЕД магнифером, если есть слабый враг ≤ 1 жизни (попытка добить)
  if (view.selfPlayer.classId === 'god' && view.selfPlayer.classState.lightningTotalUsed < 4 && !view.selfPlayer.classState.lightningUsedThisChamber) {
    const killable = aliveEnemies.find(e => e.lives <= 1);
    if (killable) return { type: 'use-ability', ability: 'lightning', targetId: killable.id };
  }

  // 2. Если бот — Двойник и видит next bullet = live и есть слабый враг: активирует нож
  if (view.selfPlayer.classId === 'double' && !view.selfPlayer.classState.knifeArmed && !view.selfPlayer.classState.knifeUsed && ctx.peekedNextBullet === 'live' && aliveEnemies.some(e => e.lives <= 2)) {
    return { type: 'use-item', itemId: 'knife' };
  }

  // 3. Существующая логика магнифера, шоколадки, выстрела
}
```

## 15. Тестирование

### 15.1. Юнит-тесты engine — новые

- Медик: chocolate +3 lives (вместо +1)
- Танк: первый live в Танка → 0 damage, second live → normal damage
- Спецназ: armor halves damage, breaks after 3 hits OR 3 rounds
- Двойник: knife armed → next live deals 2 damage, knife survives blank
- Бог: lightning damages target, decrements counters, blocked by /2 in armor
- Класс-стак: Спецназ под броней + Двойник нож → 1 damage (= 2 * 0.5)
- Дробные жизни: player at 0.5 lives is alive, takes 0.5 damage → dead

### 15.2. Юнит-тесты бота — новые

- Бог с lightning видит врага на 1 жизни → стреляет молнией
- Двойник видит peeked=live и есть слабый враг → активирует нож

### 15.3. e2e

Новый Playwright-тест: vs AI, играем за Медика, проверяем что шоколадка лечит +3.
